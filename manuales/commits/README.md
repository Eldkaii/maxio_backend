# Bitácora de commits

Esta carpeta documenta cada commit creado durante el desarrollo de Max_io.

Cada archivo debe incluir:

- El hash y el mensaje del commit.
- El objetivo y los archivos principales modificados.
- Qué quedó listo y verificado.
- Qué partes son temporales, de prueba o requieren configuración externa.
- Qué queda pendiente antes de considerar la funcionalidad lista para producción.

Los nombres siguen el formato `AAAA-MM-DD-<tipo>-<tema>.md`.
